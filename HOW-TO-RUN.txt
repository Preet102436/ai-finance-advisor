=====================================================================
  AI FINANCE ADVISOR - INSTALL AND RUN GUIDE (Windows)
=====================================================================

---------------------------------------------------------------------
 STEP 1 - INSTALL THESE PROGRAMS FIRST (one time)
---------------------------------------------------------------------

 1. Python 3.11 or newer   https://www.python.org/downloads/
      -> during install tick "Add python.exe to PATH"

 2. Node.js (LTS version)  https://nodejs.org/

 3. PostgreSQL (16 or 17)  https://www.postgresql.org/download/windows/
      -> when the installer asks for a password, enter:  postgres
      -> keep the default port 5432

 4. (Optional) Tesseract OCR - only needed for receipt photo upload
      https://github.com/UB-Mannheim/tesseract/wiki
      -> install to the default folder C:\Program Files\Tesseract-OCR\


---------------------------------------------------------------------
 STEP 2 - GET THE PROJECT
---------------------------------------------------------------------

 Clone the repository, or on GitHub click Code > Download ZIP and
 right-click the zip > "Extract All...", e.g. to:
    C:\ai-finance-advisor

 (Any folder works. Below, <PROJECT> means the folder you extracted to,
  the one that contains INSTALL.bat and START.bat.)


---------------------------------------------------------------------
 STEP 3 - INSTALL (one time)
---------------------------------------------------------------------

 EASY WAY:
   Right-click INSTALL.bat > "Run as administrator"
   Wait until it says "Install complete".

 It installs the Python + Node packages, creates backend\api\.env,
 and creates the finance_advisor database with all its tables.


---------------------------------------------------------------------
 STEP 4 - RUN THE APP (every time)
---------------------------------------------------------------------

 EASY WAY:
   Double-click START.bat
   Two windows open (Backend + Frontend) and the browser opens
   http://localhost:5173 . Keep both windows open while using it.

 Then: click Register, create an account, and log in.
 Bank link demo login:  demo_user / demo1234
 (or click "Use demo credentials")

 To STOP: close the Backend and Frontend windows.


---------------------------------------------------------------------
 MANUAL WAY (same thing, typed in PowerShell)
---------------------------------------------------------------------

 One-time install (PowerShell as Administrator):

    cd <PROJECT>
    python -m pip install -r backend\api\requirements.txt
    cd <PROJECT>\frontend
    npm install
    cd <PROJECT>
    powershell -ExecutionPolicy Bypass -File .\setup-db.ps1

 Every time - Window 1 (Backend):

    cd <PROJECT>\backend\api
    python -m uvicorn main:app --reload
      wait for: Application startup complete.

 Every time - Window 2 (Frontend):

    cd <PROJECT>\frontend
    npm run dev
      wait for: Local: http://localhost:5173/

 Open:  http://localhost:5173


 Example, if you extracted to C:\ai-finance-advisor :
    cd C:\ai-finance-advisor\backend\api
    cd C:\ai-finance-advisor\frontend


---------------------------------------------------------------------
 TROUBLESHOOTING
---------------------------------------------------------------------

 INSTALL.bat says "Python not found" / "Node.js not found"
    -> install it (Step 1), close the window, run INSTALL.bat again.

 "Password reset failed" during install
    -> run INSTALL.bat with right-click > Run as administrator.

 "Failed to fetch" on login/register
    -> the Backend window isn't running or shows an error.
       Close both windows and double-click START.bat again.
       If the Backend window says "password authentication failed",
       run INSTALL.bat again as administrator.

 "uvicorn is not recognized"
    -> use:  python -m uvicorn main:app --reload

 npm error Missing script: "dev"
    -> you're in the wrong folder; cd into <PROJECT>\frontend first.

 Browser opened before the app was ready (blank / can't connect)
    -> wait a few seconds and refresh http://localhost:5173

 Port 8000 or 5173 already in use
    -> an old copy is still running; close its windows, or restart PC.

 Receipt upload says Tesseract not found
    -> install Tesseract (Step 1.4), or add this line to
       <PROJECT>\backend\api\.env :
       TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe

 Alternative with Docker (no Python/Node/PostgreSQL needed):
    see QUICKSTART.md  ->  docker compose up --build
